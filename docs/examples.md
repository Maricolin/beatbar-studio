# 配套样例与练习

本页上方提供可试听的合成音频与配套下载卡片。Markdown 阅读者可直接使用下面链接。文件由 `scripts/generate-learning-examples.py` 确定性生成，不包含用户素材，也不依赖第三方音乐下载。

## 素材和预期拍点

[下载 8 秒练习音频](examples/beatbar-120.wav)

音频是 22,050 Hz、单声道、16-bit PCM WAV，120 BPM。16 次合成敲击从 0.25 秒开始，每隔 0.5 秒一次，最后一次在 7.75 秒；强弱按四拍循环。先调低系统音量试听。

```text
拍点序号：1     2     3     4     5      … 16
时间 / 秒：0.25  0.75  1.25  1.75  2.25  … 7.75
间隔：0.50 秒；120 BPM；4 拍为一组
```

示例项目中的 `strength` 是教学预设，没有伪装成实测的 `loudnessDb`。自动分析的结果应接近这些时间；以下载的标准拍点或 BPM 填充练习时，结果是确定的。

## 练习一：经典双色轨道

[下载经典双色项目](examples/classic-120.json) · [下载标准拍点 JSON](examples/beatbar-120.beats.json)

1. 在工作台点击“导入项目 JSON”，选择 `classic-120.json`。导入会新建独立项目，并先保存当前进度。
2. 将 `beatbar-120.wav` 上传到左侧。项目不携带素材 ID，首次关联会保留预设的 16 个拍点与样式。
3. 播放，观察双色交替的圆点沿经典轨道命中。选中第 1 个点应显示 0.250 秒。
4. 把主色改成自己喜欢的颜色，保存，再从项目库复制一份做对照。
5. 按预设的 640×360、24 FPS、素材合成输出。

检查点：16 拍；120 BPM；时长约 8 秒；有声音；项目库中原件与复制件相互独立。

## 练习二：双侧汇合与命中标记

[下载双侧汇合项目](examples/converge-120.json)

导入项目后关联同一 WAV。两侧竖线同步接近中间标记，命中效果为闪光。将命中标记改为星形，再调节标记大小。比较“移动鼓点图案”和“命中标记”两个控件，它们控制不同对象。

检查点：仍为 16 拍；视觉变化不应改变拍点时间。也可上传自己的透明 PNG 分别替换两个图案；图片不包含在本套下载中。

## 练习三：隔拍绿幕轨道

[下载隔拍绿幕项目](examples/green-half-time.json)

1. 导入并关联同一 WAV；项目只保留 0.25、1.25…7.25 秒的 8 个拍点，BPM 为 60。
2. 导出对话框中确认模式为“绿幕 BeatBar”，可取消保留原声音轨以方便叠加。
3. 导出 MP4，在剪辑软件中用绿色色度抠像去掉背景，再覆盖到自己的视频上。
4. 如果需要透明版本，切换到“透明 BeatBar”，输出扩展名会改为 `.webm`；在支持 Alpha 的软件中验证叠加。

检查点：8 拍、约 8 秒；绿色背景在导出文件中可见；不会因为拍点减半而把音频速度降到一半。

## 练习四：从空白手工校准

不导入项目，先新建并上传 WAV。填充 BPM 120、范围 0.25–7.75 秒，得到 16 拍。选中第 4 拍，将时间从 1.750 改到 1.800，然后输入整体偏移 `-50` ms 并应用，观察所有点提前。按两次撤销回到标准序列。

之后切到手动打点，以 0.5 倍播放速度练习录制，再按实际听感设置负向时间补偿。该练习用于熟悉交互；手工结果不要求与标准序列完全一致。

## 拍点交换练习

[下载 Funscript 脉冲样例](examples/beatbar-120.funscript)

先上传 WAV，通过时间轴“导入拍点”选择标准拍点 JSON 或 Funscript，应该恢复 16 拍。JSON 保留预设强度；Funscript 导入按 `pos >= 50` 提取拍点，强度为 1。拍点导入会替换当前点，可撤销。

## 自己重建练习文件

在项目根目录运行：

```powershell
.venv\Scripts\python.exe scripts\generate-learning-examples.py
```

它只写入 `docs/examples` 下的固定教学文件，不访问项目库与上传素材。修改脚本后运行 `--check` 可检查仓库中的练习文件是否与生成规则一致。源代码结构见 [开发、测试与文档维护](development.md)。
