# 工作台使用手册

## 工作台分区与一次创作的顺序

顶部管理项目；左侧上传与生成拍点；中央播放预览；下方时间轴精修；右侧配置视觉；右上角导出。通常按“新建 → 上传 → 分析或打点 → 校准 → 设计样式 → 保存 → 导出”完成一次创作。

## 上传、试听与素材关联

一次上传一个音频或视频，不要求同时提供两者。单文件上限 512 MiB，时长大于 0 且不超过 20 分钟；视频每边不超过 8192 像素。网页能否播放取决于浏览器解码器，后端可处理不等于浏览器可预览。视频优先使用 H.264 + AAC 的 MP4，音频练习可使用 WAV。

普通上传新素材会重置当前拍点；请先保存项目，或新建后再上传。打开缺失素材的项目、或导入未关联素材的练习项目后，首次上传会走重新关联流程，保留拍点与样式。时长变短后，范围外拍点可能被过滤，填充结束时间会限制到新素材时长，请核对原素材是否一致。

## 自动识别：先看结果，再调参数

| 控件         | 网页设置 / 含义                                             | 调整方法                                     |
| ------------ | ----------------------------------------------------------- | -------------------------------------------- |
| 识别灵敏度   | 1–100，初始 55                                              | 漏点时适当调高；多点时调低                   |
| 检测频段     | 综合 40–3000、低频 40–250、中频 250–3000、高频 3000–8000 Hz | 低频侧重鼓，高频侧重踩镲；按音乐实际内容选择 |
| 最小拍点间隔 | 网页 0.08–2 秒，初始 0.20 秒                                | 太大会吞掉密集节奏，太小容易保留多余起音     |
| 鼓点起音     | 保留检测到的真实敲击                                        | 需要保留变化和切分音时使用                   |
| 稳定节奏     | 在有足够稳定主节奏证据时过滤偏离网格的弱点                  | 不是补拍工具，不会凭空生成缺失鼓点           |

点击分析后显示后台任务进度，期间编辑锁定；可取消任务。新结果替换当前拍点，可撤销恢复。无音轨视频不能分析，但仍能手工打点、BPM 填充和导出。复杂混音、弱鼓点与人声都可能带来误检，参考 BPM 也可能出现倍速或半速。

## 手工录制与 BPM 填充

切到“手动打点”，点击“开启打点录制”，跟随播放按 `F` 或点击“打下这一拍”。结束时关闭录制。时间补偿单位是毫秒；例如 `-80` 使新打的拍点提前 80 ms，用于补偿反应延迟。

等距填充支持 BPM 20–400，间隔为 `60 / BPM` 秒；包含范围内的起止边界，区间外拍点保留，区间内原拍点会被替换。120 BPM、0.25–7.75 秒正好是 16 拍。BPM 只定义填充和吸附网格，不会拉伸媒体。

## 时间轴精修

- 单击下部拍点选择；拖动修改时间；双击添加；`Delete` 删除所选点。
- 上方标尺或播放头用来连续定位；空白位置单击定位。
- 滚轮以鼠标下方的时间为中心缩放；`Shift+滚轮`、横向滚轮、中键拖动平移。
- “适应全长”“定位播放头”“上一拍 / 下一拍”用于快速导航；关闭播放跟随可固定视口。
- 开启“吸附 ¼ 拍”后，仅当接近网格 10 个显示像素时吸附；按住 `Alt` 临时绕过。
- 一次拖动只生成一次撤销记录。撤销主要针对拍点编辑，不能把它当作项目切换或全部样式的全局历史。

所选拍点可直接输入秒数和强度。手工点的强度范围为 0.1–1；25 ms 内已有拍点时，添加动作会提示而不重复插入。“整体偏移”单位是 ms，正数延后、负数提前；移出素材范围的点会被删除，可撤销。“隔拍保留”按排序后的索引保留第 1、3、5…个点，不会重新估算节奏。

## 视觉参数与预览

| 参数组     | 作用与注意事项                                                 |
| ---------- | -------------------------------------------------------------- |
| 色盘       | 六套颜色预设；之后仍可独立调整主色、副色、轨道底色和纯音乐背景 |
| 鼓点颜色   | 统一主色、双色交替、强度渐变、随分贝深浅                       |
| 图案       | 圆点、竖线、菱形、三角、星芒、胶囊、六边形、心形或上传图片     |
| 节拍条类型 | 经典轨道，或双侧汇合竖线；汇合方案会联动居中标记和运动方式     |
| 运动方向   | 右向左、左向右、双侧汇合；`speed` 表示提前出现的秒数，不是 BPM |
| 轨道       | 调整宽度、粗细、纵向位置与命中标记位置                         |
| 命中标记   | 独立设置图案、颜色、大小或图片，与移动鼓点图片分开             |
| 命中动效   | 涟漪、闪光、粒子爆发或关闭；持续时间与强度可调                 |
| 预览背景   | 素材合成、绿幕、透明；最终输出仍以导出对话框为准               |

两类自定义图片都支持 PNG / JPG / WebP；每张不超过 2 MiB，每边不超过 4096 像素，解码后按比例缩略。使用透明 PNG 可避免不透明矩形背景。图案嵌入项目 JSON，交换项目时会一起分享。

“分贝深浅”优先使用原始采样中起音前 10 ms 至后 40 ms 的 RMS dBFS，不是声压级，也不随电脑音量键变化。没有实测响度的手工点和旧项目按强度估算，界面显示“手工强度”。调整暗色/亮色阈值可改变对比，上限必须高于下限。重新分析会得到新拍点和实测响度，也会替换旧拍点。

## 项目保存、切换与备份

编辑后约 900 ms 触发自动保存；任务繁忙时延后。点击“保存项目”或 `Ctrl+S` 可手动保存。只有“已保存到本机”表示这次请求完成；有更改、正在保存和保存失败时不要把关闭页面当作保存动作。

项目库支持搜索项目名/素材名、打开、复制、删除；顶部名称输入可改名。切换、新建和导入前会先保存当前进度，保存失败会阻止切换。删除需要确认，只删除项目记录，不删除音视频。多窗口同时修改同一项目可能出现修订冲突：先导出当前 JSON，再刷新读取最新版本，按需将备份导入为独立项目。

项目包含拍点/响度、BPM、样式、两张内嵌图片、导出设置、识别控件、播放位置、时间轴缩放/滚动和选择状态。撤销历史、任务、下载列表和浏览器文件夹授权不跨项目恢复。

跨电脑带走作品时，请同时备份项目 JSON 和原始素材。整体迁移可在停服后备份整个数据目录；默认是 `data/media`、`data/projects`、`data/exports`。浏览器 localStorage 只存上次项目 ID，不是作品的唯一存储。

## 拍点 JSON 与 Funscript

拍点导入用于替换当前项目的拍点，需要先上传素材；完整项目导入则创建独立项目。拍点支持数字数组或含 `time` / `strength` 的数组。Funscript 将 `pos >= 50` 的 action 作为拍点，`at` 从毫秒换算成秒；复杂连续运动数据需自行整理。导出 Funscript 是每拍一个由 0 到 100 的单向脉冲，不是任意运动脚本的无损往返。

## 导出与保存位置

| 模式         | 生成内容                                    | 场景                           |
| ------------ | ------------------------------------------- | ------------------------------ |
| 素材合成     | MP4 / H.264，可选 AAC；纯音频使用背景色画布 | 可直接播放与分享               |
| 绿幕 BeatBar | MP4 / H.264，背景 RGB 0,255,0，可选 AAC     | 剪辑软件色度抠像               |
| 透明 BeatBar | WebM / VP9 Alpha，可选 Opus                 | 支持 WebM Alpha 的剪辑软件叠加 |

所有模式导出完整素材时长。先用 640×360、24 FPS 验证，再提高质量。每边支持 64–1920 像素、最高 60 FPS；还受 180,000 帧与 1,000,000,000,000 总像素帧预算共同限制。无音轨素材不生成空音轨。透明轨道外背景透明，轨道底色本身不透明；部分播放器显示黑底，应在支持 Alpha 的剪辑软件里验证。

普通下载由浏览器决定保存目录。选择完整路径时，会先打开系统保存选择器，取消则不启动渲染。选择文件夹时，同名文件附加序号，刷新页面需重新授权。功能依赖浏览器支持；不支持时可使用普通下载。命名中的路径字符会被规范化，实际目录通过选择器设置。若额外保存失败，后端成品和下载列表仍可用于重试。

| ----------------------- | ---------------------- |

在文本输入框编辑时，多数创作快捷键会让位给输入；保存快捷键仍可使用。

## 常见问题排查

1. **网页打不开**：确认服务窗口仍在运行，检查本机端口和 `/api/health`，不要直接打开 HTML。
2. **能分析但不能预览**：转为浏览器支持的媒体编码；后端和浏览器不是同一个解码器。
3. **没声音或分析失败**：确认素材包含音轨；纯静音不会得到有意义的拍点。
4. **导出慢/资源超限**：降低分辨率、FPS 或使用更短素材；独立最大值不表示所有极限组合可同时使用。
5. **保存失败**：保留页面，恢复本地服务或磁盘空间后点保存重试；有冲突先另存 JSON。
6. **更新后页面旧/文档加载失败**：重新启动服务并强制刷新；检查部署时是否保留根目录的 `docs` 文件夹。
