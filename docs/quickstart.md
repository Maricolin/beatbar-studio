# 五分钟快速上手

目标：使用配套的 8 秒、120 BPM 合成音频，完成上传、拍点编辑、保存项目和 MP4 导出。这里的“五分钟”指操作步骤，首次安装和渲染耗时取决于电脑环境。

## 1. 启动应用

Windows 双击根目录的 `start.bat`，保持命令行窗口打开，等待浏览器打开本机工作台。日常使用不需要安装 Node.js。首次启动需要 Python 3.11+，并会在依赖缺失时联网安装。

需要手动启动时，在项目根目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

浏览器访问 `http://127.0.0.1:8000/`。不要直接双击 `frontend/index.html`；页面需要本地 API。macOS / Linux 将 Python 路径替换为 `.venv/bin/python`，创建环境时通常使用 `python3`。

## 2. 准备练习文件

进入 [配套样例与练习](examples.md)，试听并下载 **beatbar-120.wav**。这段音频由项目脚本合成，不需要另找歌曲。

回到工作台，点击 **新建项目**，命名为“我的第一个节奏视频”。将 WAV 拖入左侧素材区域，等待显示素材信息和波形。

## 3. 得到第一组拍点

可以任选一种方式：

- **学习自动识别**：选择“自动识别”，保持灵敏度 55、综合节奏 40–3000 Hz、最小间隔 0.20 秒，点击“分析音乐，生成拍点”。等待进度完成后播放试听。
- **得到确定的练习结果**：将等距节拍填充设为 BPM `120`、起始 `0.25` 秒、结束 `7.75` 秒，点击“填充选定时段”。应得到 **16 个拍点**，每两个拍点相隔 0.5 秒。

自动识别和等距填充都会改变当前拍点；可以撤销。参考 BPM 用于辅助编辑，不会改变音频播放速度。

## 4. 试看并修改一拍

按 `Space` 播放或暂停。单击时间轴下部的一条拍点竖线，查看其精确时间和强度。将它拖动一点，再按 `Ctrl+Z` 撤销。上方标尺用于拖动播放头；下部双击可添加拍点。

右侧选择“双色交替”和喜欢的图案；想看中心汇合效果，将“节拍条类型”设为“双侧汇合 · 竖线节拍条”。切换样式时可直接看实时预览。

## 5. 保存并验证恢复

顶部输入项目名称，点击 **保存项目** 或按 `Ctrl+S`。等待状态显示“已保存到本机”。刷新页面后，应恢复该项目的拍点与样式。只关闭浏览器不会删除本机数据；下一次仍需启动本地服务。

项目库位于服务端数据目录，浏览器只记住上次使用的项目 ID。换浏览器后可从项目库手动打开。

## 6. 导出第一段视频

1. 点击右上角“导出视频”。
2. 选择 **素材合成**，分辨率 `640×360`，帧率 `24`，保留原声音轨。
3. 文件名填写“我的第一个节奏视频”。先使用“浏览器下载目录”。
4. 点击“开始导出”，等待渲染完成，在右下角下载列表下载 MP4。

应得到约 8 秒的带声音视频，节奏图案在 `0.25、0.75、1.25…7.75` 秒依次命中。预览背景与最终导出模式分别设置，导出前再核对一次。
