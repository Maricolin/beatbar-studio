# BeatBar Studio 验收报告

> 记录日期：2026 年 11 月 26 日。以下结果是本次文档、学习中心、项目管理、调用客户端和部署说明更新的范围内验收，不是对所有操作系统、浏览器或真实视频素材的性能承诺。

## 交付范围

- 11 章中文教程：快速上手、完整操作、样例、架构、前端与后端逻辑、API、部署、源码索引和开发维护。
- 网页学习中心：目录、全文搜索、锚点、代码复制、Markdown 下载、音频试听和练习项目下载。
- 三个可导入项目、一个 8 秒 22,050 Hz 单声道 16-bit PCM 示例音频、拍点 JSON 和 Funscript。
- 本机项目库：新建、改名、搜索、复制、删除、自动保存、恢复、JSON 导入导出和缺失媒体重新关联。
- scripts/beatbar_client.py 的 Python 客户端及 health、analyze、render CLI；性能采样、学习素材、源码索引、文档和浏览器测试脚本。

## HTTP 与调用结果

- WAV 上传返回 200，媒体时长 8 秒且有音轨；分析任务返回 202，完成后得到 16 拍 / 120 BPM。
- 项目创建与列表返回 200，项目修订号为 1；导出任务返回 202 并完成下载。
- 部分下载请求返回 206 Range；教程 Python 与 CLI 的四份输出均核对字节数和 SHA-256，四份性能成品另核对容器签名。
- CLI 对已有输出文件返回错误并保持原文件哈希不变。

## 复现命令

在已安装依赖的仓库根目录执行：

    pnpm check
    pnpm test:unit
    pnpm test:projects
    pnpm test:docs
    .venv/Scripts/python.exe -m unittest discover -s backend -p test_*.py -v

HTTP、Python、CLI 和性能复现步骤见 [API 与调用示例](api.md)、[部署与性能](deployment.md)及[开发维护说明](development.md)。

## 边界与限制

- 性能数据是合成 WAV 的单次顺序样本；未测并发负载、进程树峰值内存、源视频解码或其他设备性能。
- 原生操作系统文件选择器的权限未人工检查，浏览器回归使用受控选择器和保存句柄。
- 截图已保存但未进行人工视觉审查；布局结论来自真实浏览器尺寸、几何和可见 DOM 检查。
- 本轮运行验证限 Windows 与专用 Chrome；其他操作系统和浏览器需在目标环境重跑。
- 一次额外文档复测在项目读取处出现 `MemoryError`。关闭已完成测试的专用浏览器与 API 后，同一命令未改代码即通过；具体根因未确定。
- 本地 `artifacts/learning-verification.json` 记录完整命令、哈希和清理状态；`artifacts/acceptance-20261126/` 保存原始 HTTP、CLI、浏览器结果和生成成品。上述运行产物按仓库 `.gitignore` 规则不提交。
