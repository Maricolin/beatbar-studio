## 三个需要先分清的对象

- **素材**：上传的音频或视频本体，保存在本机数据目录中。
- **项目**：拍点、样式、素材关联和编辑设置。项目 JSON 不打包音视频；内嵌的自定义图片会随 JSON 一起保存。
- **导出成品**：经过后端渲染的视频。保存项目和导出视频是两个独立动作。

## 推荐学习路线

1. 阅读快速上手，完成一段 8 秒的练习作品。
2. 在样例页面试听示例，分别尝试经典轨道、双侧汇合和隔拍绿幕。
3. 用使用手册处理自己的素材，并测试一次关闭页面后的项目恢复。
4. 开发者从结构图进入前后端说明，最后通过源码索引定位实现。

文档记录当前实现，并明确区分网页默认值、API 默认值和示例设置。检测结果依赖音乐内容；合成练习的标准拍点不是对任意歌曲的准确率承诺。
