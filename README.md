# BeatBar Studio

本地运行的中文 Web 节奏条生成工具。单独上传音乐或视频即可创作，支持自动识别、手工打点、时间轴编辑、主题色盘、自定义鼓点图案、双侧汇合和命中动效，以及绿幕、透明或合成视频导出。参考项目与组件来源见 THIRD_PARTY_NOTICES.md。

## 视觉样式

- **6 套色盘**：青柠、极光、日落、糖果、海洋与单色；主色、副色、轨道底色和纯音乐画布背景均可自定义。
- **3 种配色**：统一主色、双色交替、按拍点强度在主副色之间渐变。
- **7 种内置图案**：圆点、菱形、三角、星芒、胶囊、六边形和爱心；也可上传 PNG / JPG / WebP 图片。透明图案保留透明度，非方形图案保持比例。
- **3 种运动**：从右向左、从左向右、双侧同时向中心汇合；汇合模式自动将命中线置于中心。
- **3 种命中动效**：涟漪、闪光与粒子爆发，可调持续时间、强度，也可关闭；鼓点大小独立调节。
- **实时样式预览**：没有导入素材时也可试色与预览动画；浏览器预览和视频导出使用相同的参数。

## Windows 一键启动

1. 安装 Python 3.11 或更高版本并加入 PATH。
2. 双击根目录的 start.bat。首次启动会创建 .venv 并安装 requirements.txt（需要网络）；日常启动不需要 Node.js。
3. 服务就绪后自动打开 http://127.0.0.1:8000 。保留命令行窗口，按 Ctrl+C 停止服务。

首次安装后可用以下命令更新依赖并手动启动；如默认包源连接慢，可选用镜像源：

```powershell
.venv/Scripts/python.exe -m pip install -r requirements.txt --timeout 30 -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/Scripts/python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

macOS / Linux 可使用 Python venv 安装同一 requirements.txt，执行相同 uvicorn 模块启动。应用不依赖系统安装 FFmpeg，imageio-ffmpeg 提供编码程序。

## 使用流程

1. **导入媒体**：点击或拖入单个音乐文件（MP3、WAV、M4A、AAC、FLAC、OGG 等）或视频文件。音乐会以可自定义背景色的节奏画布预览；视频建议 H.264 + AAC 的 MP4，便于浏览器播放。
2. **自动识别**：选择综合、低频鼓点、中频敲击或高频踩镲，调节灵敏度和最小拍点间隔，再点击“分析音乐，生成拍点”。结果覆盖当前拍点，可撤销。
3. **手工录制**：切换“手动打点”，开启录制，播放时按 F 或点击打点按钮。时间补偿负数可将拍点提前。A 在当前时间直接添加拍点。
4. **调整节奏**：时间轴单击定位，双击添加，拖动拍点调整时间；选中后可精确填写秒数和强度，Delete 删除，Ctrl+Z 撤销。支持缩放、逐帧移动、整体偏移、保留隔拍和 BPM 等距填充。
5. **设计轨道**：选择主题色盘和配色模式，选用 7 种内置图案或上传图片；切换左右单向运动或双侧汇合，调节涟漪、闪光、粒子爆发的持续时间与强度。还可调整鼓点大小、命中线位置、轨道宽高、垂直位置和提前可见时长。右侧实时小预览可直接试效果。
6. **保存项目**：下载项目 JSON，包含素材 ID、拍点、BPM、视觉样式及自定义图案；打开项目可恢复本地仍存在的素材及波形。若素材已移除，按提示重新上传原素材。项目文件不包含音乐或视频本体，换机器需同时保留原文件。
7. **导出**：选背景模式、分辨率、帧率及是否保留原音频，等待任务完成后点击下载。可以连续导出多种版本，下载列表保留在当前页面。

## 视频格式

| 模式         | 容器 / 编码                     | 用途                                                                   |
| ------------ | ------------------------------- | ---------------------------------------------------------------------- |
| 素材合成     | MP4 / H.264，音频可选 AAC       | 视频保留原画面并等比缩放补边；纯音乐生成自定义背景色的节奏画布             |
| 绿幕 BeatBar | MP4 / H.264，音频可选 AAC       | 单独绿幕轨道，背景 RGB 0,255,0；有损压缩后边缘需在剪辑软件调节抠像容差 |
| 透明 BeatBar | WebM / VP9 Alpha，音频可选 Opus | 真正透明背景的独立轨道，适合支持 WebM Alpha 的剪辑软件                 |

透明视频在部分播放器里显示黑底不代表没有 Alpha；使用支持 Alpha 的剪辑软件叠加验证。FFmpeg 检查时输入前指定 -c:v libvpx-vp9，原生 VP9 解码器可能不输出 Alpha。轨道背景本身有颜色，轨道以外透明。

## 限制与处理方式

- 单个音频或视频文件最大 512 MB、最长 20 分钟；输出最长边 1920、最高 60 FPS。原视频更大时，“跟随原视频”会等比缩小到最长边 1920；可选横屏与竖屏输出。
- 音频检测是本地频谱起音与峰值分析，不是乐器分离模型。人声、复杂混音、弱鼓点和变速音乐可能出现漏点、多点或半拍 BPM，需调整频段、灵敏度或手动校准。
- 视频时长、帧率和尺寸越大，渲染越慢。编码在本机服务执行，页面显示进度并支持取消；处理期间锁定编辑，确保输出与提交时拍点一致。
- 只需上传一个音频或视频，不要求同时提供两者。纯音乐支持试听、自动识别和全部三种导出模式；无音轨视频支持手动打点和 BPM 填充，导出不会凭空添加音轨。
- 自定义图片最大 2 MB，宽高各不超过 4096 像素；项目 JSON 会内嵌图案，跨项目恢复无需重新选择图片。
- 上传素材、波形元数据和导出文件保存在 data/media 与 data/exports，暂不自动清理。关闭服务后可自行删除不需要的文件以回收空间；删除原素材后项目需重新关联。
- 默认仅监听本机 127.0.0.1，没有登录、用户隔离或云存储。若部署到外部网络，需要自行增加认证和存储管理。
- 本地服务断开时任务查询会重试；服务重启后内存中的任务状态不会恢复。

## 快捷键

| 按键                        | 操作               |
| --------------------------- | ------------------ |
| Space                       | 播放 / 暂停        |
| F                           | 录制开启时打点     |
| A                           | 当前时间添加拍点   |
| ← / →                       | 以当前帧率步进一帧 |
| Shift + ← / →               | 微调选中拍点 10 ms |
| Delete                      | 删除选中拍点       |
| Ctrl + Z / Ctrl + Shift + Z | 撤销 / 重做        |
| Ctrl + S                    | 保存项目           |

另支持拍点 JSON 导入导出、Funscript 导入导出。Funscript 导入将位置 >=50 的 action 视为拍点，适合本工具导出的单向脉冲数据；复杂连续运动脚本可能需要手动整理。

## 开发与测试

前端是无构建依赖的原生 HTML/CSS/JavaScript，后端 FastAPI + NumPy/SciPy + Pillow + FFmpeg。

```powershell
.venv/Scripts/python.exe -m pip install httpx2
.venv/Scripts/python.exe -m unittest backend.test_backend -v
```

Node.js 22+ 仅供可选开发工具使用，`pnpm install` 后运行 `pnpm check` / `pnpm format`。

浏览器回归测试需要先启动本地服务，并用独立测试配置启动 Chrome（不要使用日常浏览器配置）：

```powershell
.venv/Scripts/python.exe scripts/generate-fixtures.py
& "$env:ProgramFiles/Google/Chrome/Application/chrome.exe" --remote-debugging-port=62880 --user-data-dir="$PWD/artifacts/qa-profile" --headless=new http://127.0.0.1:8000
node scripts/browser-test.mjs 62880
node scripts/visual-browser-test.mjs 62880
```

后端 16 项测试覆盖有声/无声视频、纯音乐、三种输出模式、透明度、自定义背景色、图案比例、双侧汇合与动效。两套浏览器脚本检查编辑流程、新样式控件、项目恢复、导出及多尺寸页面溢出；测试生成的媒体、截图与报告保存在 artifacts，不纳入版本管理。
